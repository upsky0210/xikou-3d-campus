# 溪口國小 3D 校園

臺北市文山區溪口國民小學的 3D 互動校園地圖：選角色、在校園裡走動、找教室、自動帶路、看 360° 實景導覽。

## 功能

- 方塊風 3D 校園（可切換簡約風），B1～4F 與頂樓
- 男學生 / 女學生角色，穿學校制服
- 找教室：輸入班級（503、五年三班）、教室號碼或名稱
- 帶我去：黃色路線導航，會自動經過樓梯
- 360° 實景導覽：19 個景點、32 張環景照，中英文介紹與語音

## 修改資料

| 要改的東西 | 檔案 |
|---|---|
| 教室名稱、位置、班級 | `js/campus-data.js` |
| 360° 景點、介紹文字、位置 | `js/pano-data.js` |

改完後把 `index.html` 和 `js/app.js` 裡的 `?v=` 數字加 1，瀏覽器才會讀到新版。

## 本機預覽

```bash
python -m http.server 5173
```

再打開 http://localhost:5173
