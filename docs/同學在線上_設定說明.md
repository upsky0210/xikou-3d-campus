# 「同學在線上」設定說明（第 1 步）

網站的程式已經上線，但**資料庫還沒設定之前，按鈕不會出現**。照下面做完才會打開，而且一開始只開給測試名單。

## 1. 貼上規則（2 分鐘）
1. 開 Firebase 主控台 → `xikou-3d-campus` → Realtime Database → 上面的「規則」分頁。
2. 開 <https://upsky0210.github.io/xikou-3d-campus/database.rules.json>，全部複製。
3. 貼到規則框，蓋掉原本的，按「發布」。出現紅字就把紅字貼給 Claude。

## 2. 把自己設成管理員（1 分鐘）
1. 切到「資料」分頁。滑鼠移到最上面那一行，按「＋」。
2. 依序新增，做出這個樣子（值要選「布林」`true`，不要打成文字）：

```
online
└ admins
   └ 你的帳號@skps,tp,edu,tw : true
```

**email 的「.」全部換成半形逗號「,」，而且全部小寫**（資料庫的名稱不能有「.」）。
學生網域的管理帳號也要管的話，再加一個 `帳號@st,skps,tp,edu,tw : true`。

`online/admins` 只能在主控台改，網站改不了。

## 3. 打開（1 分鐘）
1. 用那個帳號登入 3D 校園，上面會出現「👥」，按下去。
2. 下面有「🔧 管理」：
   - **總開關**：打開。
   - **開放對象**：先維持「只有測試名單」。
   - **時段**：預設 7 點到 21 點。
   - **測試名單**：加一個學生帳號。
3. 兩台電腦各登入一個帳號，都按「加入」，走到同一層樓，看看有沒有互相看到。

## 學校網路
防火牆要放行（含 WebSocket）：`*.firebasedatabase.app`、`*.firebaseio.com`。
按「加入」後 12 秒還連不上，會跳出「連線比較久，可能是人數滿了或網路擋住」。

## 要知道的限制
- 免費方案：同時 100 個連線、每月下載 10 GB，超過當月會被停用（Firebase 主控台 → 用量 看得到）。
- 按「加入」的人才會連線；分頁放到背景 3 分鐘自動離開。
- 出事：管理面板關總開關，全部的人馬上離開；也可以在名單上按「停用」某個帳號。

## 改規則
不要直接改 `database.rules.json`，改 `tools/make-database-rules.mjs`，再跑：
`node tools/make-database-rules.mjs`、`node tools/test-database-rules.mjs`，全過再貼到主控台。
